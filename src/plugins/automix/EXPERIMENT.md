# AutoMix beta experiment

This is an unmerged experiment. It is disabled by default and requires Crossfade to be disabled. Its plain plugin menu chooses four or eight beats, capped at six seconds by default. Native playback continues when ownership or stream compatibility is uncertain.

This narrower prototype adapts weighted onset autocorrelation and Krumhansl-Kessler key profiles from Pear Desktop PR #4749 by **@SurajBhari**, pinned at `31d35d3a1149bd273e5cd0d3794844d16664aa14`. Original upstream modules inspected: `analysis.ts`, `key.ts`, `planner.ts` and configuration. The upstream `signalsmith-stretch@1.3.2` dependency, Apple/catalog analysis, effects and UI are deliberately outside this prototype. MIT project licensing and original contributor attribution are retained.

The raw shared media source feeds one analyser tap. A fixed ring retains at most 400 energy/chroma frames, representing approximately twenty seconds at 20 Hz. Wall-clock and audio-clock cadence are checked together; timer gaps outside 20–100 ms or clock divergence discard the history. The tap and ring retire on pause, seek, conflict, source replacement, context loss or stop. There are no full-track analysis downloads, decoded PCM buffers or analysis workers. The numerical payload is bounded to about 67 KiB plus JavaScript object overhead. At least eight seconds of steady signal are needed for tempo analysis; shorter or uncertain input uses a three-second equal-power fallback.

Tempo estimates determine a four/eight-beat overlap. A clearly tonal outgoing passage is limited to four beats because the incoming harmony is unknown. The resulting plan directly configures the existing Crossfade handoff and envelopes. It uses the validated shared audio-stream resolver, only for the outgoing copy, capped here at 16 MiB and tracks no longer than ten minutes. No source or output graph is replaced, and the original shared graph remains authoritative for EQ, Reverb, Pitch and volume/mute controls.

Crossfade and AutoMix have separate controller identity slots and one shared transition lease, retained until teardown completes. Only one physical stream request and one transition owner are admitted. Retired requests retain the existing physical slot until settlement; AutoMix and an explicitly mode-rearmed guarded Crossfade consumer may wait at most ten seconds with owner fences. Ordinary Crossfade readiness replacement retains its previous no-wake cancellation policy. Stream/client fetches have an eight-second abort deadline. Native current/next identity, queue, playback episode, source, context and graph checks remain inherited from the accepted transport. Graph readiness rebinds the latest API after replacement and listeners retire on stop/pagehide.

There is **no incoming-track analysis, key matching, beat-phase locking, time stretching, queue reordering, album logic, Apple/Spotify-equivalent mixing, or listening/hardware qualification**. This prototype selects musical overlap lengths; it does not synchronize two beat grids. Physical output remains unverified.

Focused checks: `pnpm exec playwright test --config tests/automix.playwright.config.ts`. Existing transport/composition checks: `pnpm exec playwright test --config tests/automix-regression.playwright.config.ts`. Native fixtures are owned local media in muted Chromium, separate from user accounts, production profiles and packaged app startup/performance measurements.
